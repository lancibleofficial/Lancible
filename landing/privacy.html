Приложение для компьютера проверяет обновления в хранилище релизов, приложение для Android — по файлу с номером последней версии на GitHub. При этом передаются только обычные данные запроса: IP-адрес и версия приложения.

Сіз сайтты немесе веб-нұсқаны ашқанда, ал қосымша серверлерге жүгінгенде, хостинг провайдерлері (5-бөлім) IP мекенжайын, сұрау уақытын және браузер не құрылғы түрін автоматты түрде көреді. Бұл жазбалар беттерді жеткізу, шабуылдардан қорғану және қателерді іздеу үшін керек; олар бойынша сіздің профиліңізді құрмаймыз. Жұмыс журналының қызметтік беті (/logs) жазбаларды тікелей біздің дерекқордан оқиды, сондықтан оның келушісін Supabase та осылай көреді. Негіз — қызметтің қауіпсіз жұмысына деген заңды мүдде.

Компьютерге арналған қосымша жаңартуларды релиздер қоймасынан, Android қосымшасы GitHub-тағы соңғы нұсқа нөмірі бар файлдан тексереді. Тек қарапайым сұрау деректері беріледі: IP мекенжайы және қосымша нұсқасы.
